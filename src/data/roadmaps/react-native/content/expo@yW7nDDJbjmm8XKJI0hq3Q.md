Expo is an open-source framework and a set of tools built around React Native that helps you build, deploy, and test mobile apps faster — especially if you don't want to deal with native code (like Java, Swift, or Xcode).

What Expo Includes:
CLI (create-expo-app) → To create apps quickly
Expo Go App → Run apps on your phone without building them
Expo SDK → Pre-built APIs (camera, notifications, location, etc.)
Expo Snack → Online code editor to run React Native in browser
EAS Build → Build real native binaries (APK/IPA) in the cloud
